# Mainbin-Web

> **Status: paused since May 2026, and the repository name is a typo of Mailbin.** The app it
> advertises is [Mailbin](https://github.com/giddypergrid/Mailbin), which is itself paused. Current
> work is [Fine Print](https://github.com/giddypergrid/nzfineprint-backend) and
> [NZ Bird Sound](https://github.com/giddypergrid/NZBirdSoundDatabase-AWS).

The marketing site for Mailbin, a Gmail triage app. One page: what the app does, and a drag-to-swipe
demo with a colour reveal behind the card, so a visitor can try the gesture in the browser.

---

React, TypeScript, Vite.
